## lora-kit: LoRA from scratch on numpy

`lora_kit/` is a small, dependency-free (no torch) implementation of
Low-Rank Adaptation (LoRA), built on top of numpy with hand-written
forward and backward passes.

### Package layout

- `lora_kit/linear.py` — a plain `Linear` layer: `y = x @ W.T + b`.
- `lora_kit/lora.py` — `LoRALinear`: wraps a frozen base `Linear` with a
  trainable low-rank update `B @ A` (B initialized to zero, A random, so
  the adapter starts as a no-op). Forward:
  `y = x @ W.T + b + (alpha/r) * (x @ A.T) @ B.T`. Includes a manual
  `backward()` that returns gradients for `A` and `B` only — `W` and `b`
  are frozen and never differentiated.
- `lora_kit/optim.py` — `Adam`, a from-scratch optimizer (moment
  estimates, bias correction) that operates on named numpy-array params.
- `lora_kit/merge.py` — `merge()` / `unmerge()` to fold `B @ A` into a
  plain `Linear` (or split it back out) for inference without the LoRA
  matrices.
- `lora_kit/adapters.py` — `AdapterManager`: holds several named LoRA
  adapters sharing one frozen base and lets you `activate()` / swap
  between them.
- `lora_kit/io.py` — `save_adapter()` / `load_adapter()`: persist just the
  small `(A, B, r, alpha, metadata)` adapter state to a `.npz` file,
  independent of the (larger) frozen base weights.

### Usage

```python
import numpy as np
from lora_kit.linear import Linear
from lora_kit.lora import LoRALinear
from lora_kit.optim import Adam

rng = np.random.default_rng(0)
base = Linear(20, 10, rng=rng)          # frozen "pretrained" layer
lora = LoRALinear(base, r=8, alpha=8, rng=rng)
opt = Adam({"A": lora.A, "B": lora.B}, lr=0.05)

x = rng.normal(size=(256, 20))
y_target = ...  # your training targets

for _ in range(500):
    y_pred = lora.forward(x)
    grad_output = (y_pred - y_target) / x.shape[0]
    grads = lora.backward(grad_output)
    opt.step(grads)
```

### Examples

- `examples/finetune_demo.py` — freezes a random "pretrained" `Linear`,
  then adapts it with LoRA (r=8) on a toy shifted linear regression task
  (the target is the base mapping plus an unknown rank-8 shift), trained
  with the from-scratch `Adam`.
- `examples/rank_sweep.py` — trains LoRA adapters of rank
  `[1, 2, 4, 8, 16]` against a toy task whose true underlying shift has
  rank 6, and reports final loss/RMSE per rank.
